How to Share Files Using a Personal Hotspot

A practical guide from PairDrop.

A personal hotspot is usually thought of as a way to share the internet, but it can also create a local network between your devices when there is no Wi-Fi router at all. One phone creates the network, other devices join it, and files move directly between them. This is useful on a bus, in a car, at a remote site, or in a building with no Wi-Fi. This guide explains how to set up a hotspot for file sharing, how to keep it private, and what to do when devices cannot see each other on the hotspot network.

Set up the hotspot on your phone

Open the hotspot settings on your phone, turn the hotspot on, and give it a clear name and a strong password. Turn off mobile data if you do not want the hotspot to use data, because the local transfer does not need it. Keep the phone charged or plugged in, because a hotspot uses battery. Tell the other person the network name and password, and have them join the hotspot network from their Wi-Fi settings. Once they are connected, use a local sharing app or a file manager that supports Wi-Fi transfer to send the file. The devices are now on a private local network of their own.

Send files over the hotspot network

With both devices on the hotspot, open the sharing tool on the sending device, select the files, and choose the receiving device when it appears. The transfer uses local Wi-Fi speed, so large videos and photo batches move quickly. Keep both devices close to the hotspot phone and keep their screens awake until the transfer finishes. If the receiving device does not appear, check that it is connected to the hotspot network and not to another Wi-Fi network. A device can only be on one Wi-Fi network at a time, so joining the hotspot means leaving the previous network for a while.

Keep the hotspot private and safe

A hotspot with no password can be joined by anyone nearby, so always set a strong password and change it if you share it widely. Turn the hotspot off as soon as the transfer is done, because a hotspot left on drains battery and invites unwanted connections. Do not share sensitive files over a hotspot in a crowded place unless you trust the people nearby, and prefer a cable for very sensitive files. Check the list of connected devices in the hotspot settings if you are unsure who is connected, and remove any device you do not recognise.

Fix hotspot sharing problems

If devices cannot see each other, check that the hotspot is on, that the other device joined the right network, and that the VPN is off on both devices. Restart the hotspot and reconnect the other device. Move the devices closer to the hotspot phone, because the hotspot range is short. If the transfer is slow, move closer and close other apps that use the network. If the hotspot keeps turning off, plug the phone in to charge, because some phones turn the hotspot off to save battery. A short test with a small file will tell you quickly whether the hotspot network is working.

Quick tips

  • Set a strong hotspot password
  • Turn off mobile data if you do not need it
  • Turn the hotspot off when done
  • Keep devices close to the hotspot phone

Frequently asked questions

Does hotspot file sharing use mobile data?

No, if mobile data is off. The devices only talk to each other over the local hotspot network, so no data is used for the transfer itself.

Can I share files with a hotspot when there is no signal?

Yes. A hotspot creates a local network even with no mobile signal. The devices connect to each other, not to the internet.

Why can the other device not see mine on the hotspot?

Check that it joined the hotspot network, that the VPN is off, and that both devices are close to the hotspot phone. Restart the hotspot and reconnect.
